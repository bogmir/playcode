- [ ] **Verse, prose or mixed: the files' label is ignored, and written wrong** - every source file labels its form on `fileDesc/extent/@ana` (372 files: `verso` 222, `prosa` 56, `versoprosa` 41, `intervenciones` 45, a count of speeches, and none 8). `TeiParser.extract_verse_count/1` reads only the number; `Catalogue.update_verse_count/1` then sets `is_verse` from the text, so the 41 `versoprosa` plays are verse and `form` stays nil. `TeiXml.build_extent/1` writes `ana="verso"` for every play, and `0 versos` for a prose play (0 is truthy). Question 23 answered 2026-10-19 in `docs/stakeholder/preguntas.html` (background in `docs/stakeholder/verso-y-prosa.html`): the text decides, as now, and `mixed` is only ever set by hand; a fourth form, "prose with occasional verse", for a play with a little verse (where it ends is still asked there: proposed under a tenth of the text by length, 71 plays in dev; 42 hold no verse); and every play's form is to be revised by hand, from a list we send (label, share of verse, Playcode's form).
